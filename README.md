# CS331-File-Tampering-Detection-System
## Description
    Create a program that monitors files and detects when someone changes, deletes, or adds a file without permission and alert the user that something changed. This will demonstrate file integrity, monitoring and assurance. We will use AI to generate a message summarizing the changes of what was changed, deleted or added, and then send a notification.
